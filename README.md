# Кругом — детский клуб

Демонстрационный сайт детского клуба: шахматы, английский, немецкий и рисование для детей.

Сайт: https://untru.github.io/krugom-kids-club/

Перенесён из https://krugom-kids-club.pchegodaev.chatgpt.site без изменения содержимого страницы.

## Публикация и редактирование

GitHub Pages публикует корень ветки `main`. Для обновления сайта измените `index.html` и отправьте коммит в `main`. Сборка и установка зависимостей не нужны. Файл `.nojekyll` отключает обработку Jekyll.

Для локального просмотра откройте `index.html` в браузере. Единственный внешний ресурс — шрифт Manrope из Google Fonts; предусмотрен системный запасной шрифт.

## Формы

Это демо-версия: анкета и вопрос сохраняются в `localStorage` текущего браузера и не отправляются администратору. Контакты клуба, реальные цены и адрес пока не подключены.
