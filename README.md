- Инструкция: https://untru.github.io/krugom-kids-club/admin/guide.html

## Редактору

В Pages CMS откройте `Untru/krugom-kids-club`, ветку `main`, раздел **Занятия и расписание**. У каждого занятия свои описание, возраст, цена, фотография и список строк расписания. Порядок элементов списка задаёт порядок карточек на сайте. Выключение **Показывать на сайте** скрывает занятие, его расписание и вариант в анкете.

Раздел **Тексты, контакты и вопросы** меняет тексты страницы, контакты и ответы родителям. Поля предназначены для обычного текста: HTML не нужен.

## Первое подключение владельцем

1. Открыть https://app.pagescms.org и войти через GitHub.
2. Установить официальное GitHub App Pages CMS, выбрав **Only select repositories → Untru/krugom-kids-club**.
3. Открыть репозиторий и ветку `main`. Конфигурация `.pages.yml` уже подготовлена.
4. При необходимости пригласить сотрудника в разделе Collaborators самого Pages CMS. Доступ выдаёт владелец; конфигурация в репозитории сама по себе доступ не предоставляет.

Готовность подключения проверяется открытием форм с существующими четырьмя занятиями. Если приложение остаётся на Loading, настройка внешнего сервиса ещё не завершена.

## Публикация

Сохранение в Pages CMS создаёт изменение в GitHub. Workflow `Publish website` проверяет данные, собирает страницу и публикует папку `dist` на GitHub Pages. При ошибке сборки сайт сохраняет последнюю успешно опубликованную версию. Изменение ошибочных данных и повторное сохранение запускают новую сборку.

Окончательная проверка — открытие сайта после успешного workflow. Сохранение в CMS и публикация являются разными шагами; распространение обновления может занять несколько минут.

## Разработчику

Node.js 22+, без внешних зависимостей:

```sh
npm test
npm run build
```

- `data/courses.json` — общий список занятий; расписание вложено в занятие.
- `data/site.json` — остальные редактируемые тексты и контакты.
- `.pages.yml` — формы Pages CMS и папка загрузки фотографий.
- `src/index.html` — шаблон оформления.
- `src/site.js` — фильтры и демонстрационная анкета.
- `scripts/render.mjs` — проверка данных, экранирование текста и генерация HTML.
- `admin/` — вход и инструкция редактору.
- `dist/` — результат сборки, не хранится в Git.

В GitHub Settings → Pages должен быть выбран источник **GitHub Actions**. Сборка генерирует готовый HTML: содержимое доступно без дополнительных запросов к CMS при посещении сайта. Фотографии хранятся в `media/`. Поддерживаются JPG, PNG, WebP и GIF.

## Заявки родителей

Форма остаётся демонстрационной: введённые данные сохраняются только в браузере посетителя и не отправляются администратору. Подключение Pages CMS не подключает приём заявок. Данные заявок нельзя добавлять в публичный репозиторий.
